# Security

If you've found a security problem in subtend.io or an ifcdesk tool, please
report it privately:

**[Report a vulnerability privately](https://github.com/Subtend-io/feedback/security/advisories/new)**

Only you and we can see the report. Please don't open a public issue for it.

We aim to acknowledge a report within a week. What's covered, what to
include, what we'll do and what not to test are in the full policy:
[subtend.io/policies/security](https://subtend.io/policies/security).
